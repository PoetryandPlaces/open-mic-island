Host setup

This makes the secret host code for Couplet Cove. Anyone who types /host and this code in the game chat can mute or kick people.

  1. Pick a code that's hard to guess: at least 20 characters and 4 words, or click Suggest a strong code and write it down somewhere safe.
  2. Click Make host key. Your browser saves a file called host-key.js.
  3. Upload host-key.js to the site, next to index.html.

Your code never leaves this page. The file only holds a locked key that your code opens. If you forget the code, just make a new key and upload the new file. Making a new key also changes the code.

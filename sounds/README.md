# Critter and island sounds

These clips replace the island's built-in synthesized sounds. If a file is missing, the
built-in sound plays instead, so it's safe to swap or remove any of them.

| File         | Used for                                          |
|--------------|---------------------------------------------------|
| `cat.mp3`    | Cat speaking in chat                              |
| `frog.mp3`   | Frog speaking in chat                             |
| `mouse.mp3`  | Rosy speaking in chat                             |
| `fish.mp3`   | Fish speaking in chat                             |
| `dog.mp3`    | Dog speaking in chat                              |
| `splash.mp3` | Jumping or wading into the ocean                  |
| `waves.mp3`  | Ocean loop, only heard near the shore             |
| `fire.mp3`   | Campfire loop, only heard near the fire           |
| `applause.mp3` | Applause when someone presses C                 |
| `wee.mp3`    | "Wheee!" when you slide down the castle's rainbow |

Keep each clip short and small (under about 200 KB) so the island loads fast.
